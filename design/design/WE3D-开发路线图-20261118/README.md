## 全局约束（来自 §十 用户拍板）

- **D1**：既有 PBR 目前不冻结，S1 再冻结为 legacy。
- **D2**：`GltfPBRMaterial` 默认切换按建议执行。
- **D3**：性能对照口径推迟到 demo 对比阶段确定；S0 只建度量能力。
- **D4**：官方样本资产/截图基线可用（须对齐资产与相机 JS）；GLSL 以原理参考为主。
- **D5**：体积云本轮不生产化，S5 单独立项。
- **D6**：编辑器目前仅规划，不提前投入。
- **D7**：不引入云端 e2e，e2e 只在本地。
